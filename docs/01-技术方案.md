## 1. 产品与系统概述

面向初高中学生的 AI 个性化教学平台，核心是"**诊断 → 定制 → 授课 → 检验 → 微调**"的学习闭环：

```
注册建档 ──▶ ①入测诊断 ──▶ 诊断报告(掌握度画像)
                                   │
                                   ▼
                             ③ 个性化教学大纲（总）
                                   │
              ┌────────────────────┴──────────────┐
              ▼                                   ▼
     ⑤ 数字人课堂(每节课) ◀── ④ PPT/课件生成     （循环 N 节课）
              │                                   ▲
              ▼                                   │
     ⑥ 课后小测 ──▶ 更新掌握度 ──▶ 大纲微调 ──────┘
```

六大业务模块：

| # | 模块 | 一句话定义 |
|---|---|---|
| ① | 入测诊断 | 新用户首次智能组卷，量化各知识点掌握度，产出报告 |
| ② | 老师智能体 | 带人设、带学生画像、带工具调用能力的 AI 老师（贯穿全程） |
| ③ | 大纲生成 | 从诊断报告 + 课标 + 时间预算生成个性化教学大纲 |
| ④ | PPT 生成 | 大纲 → 逐页课件 JSON → PPTX（下载）＋网页课件（授课） |
| ⑤ | 数字人讲解 | Live2D 数字人 + TTS + 口型同步，逐页讲解、随时提问 |
| ⑥ | 课后小测 | 每课一测，更新掌握度，微调大纲，为下节课做准备 |

## 2. 总体架构（Cloudflare 全托管）

```
┌────────────────────────────────────────────────────────────────────┐
│ 用户端：Web App（Vite + React SPA）— 学生 / 家长 / 教师视角          │
│ 含：数字人播放器（Live2D + Web Audio 口型）、课件演示器（KaTeX）       │
└──────────────────────────┬─────────────────────────────────────────┘
                           │ HTTPS
┌──────────────────────────▼─────────────────────────────────────────┐
│ Cloudflare 边缘：单个全栈 Worker（Static Assets + Hono API）         │
│  · /api/*  → Worker 代码（Hono 路由）                               │
│  · 其余路径 → 静态资源（前端构建产物，SPA fallback）                  │
│  · Turnstile 人机验证 / 速率限制 / WAF / 缓存                        │
├────────────────────────────────────────────────────────────────────┤
│ 数据与基础服务                                                      │
│  · D1 (SQLite)    主数据库：用户/题库/测评/大纲/课程/掌握度          │
│  · R2 (对象存储)  PPT、课件 JSON、TTS 音频、头像、上传素材           │
│  · KV             会话缓存、短缓存、任务状态                         │
│  · Vectorize      向量检索：讲义/错题/知识点 RAG（二期）             │
│  · Queues         异步任务：PPT/大纲/小测/TTS 生成                   │
│  · Cron Triggers  定时任务：任务重试、用量报表、D1 备份导出           │
├────────────────────────────────────────────────────────────────────┤
│ AI 服务层（经 Cloudflare AI Gateway 统一接入）                      │
│  · LLM：DeepSeek-V3.2（主力）/ GLM-Flash（免费兜底）/ 通义（备选）   │
│  · Agent 编排：Vercel AI SDK v5（流式输出 + 工具调用）               │
│  · TTS：MVP Edge-TTS → 生产 火山引擎/阿里云 TTS（Workers AI 兜底）  │
│  · 数字人：2D Live2D（pixi-live2d-display，客户端渲染）              │
│  · 内容安全：腾讯云天御 / 阿里云内容安全（文本/图片审核）             │
├────────────────────────────────────────────────────────────────────┤
│ 外部：Sentry（监控）· GitHub Actions（CI/CD）· 支付（二期）          │
└────────────────────────────────────────────────────────────────────┘
```

**为什么选"单个全栈 Worker"**：Cloudflare 官方 2026 年对新项目的推荐——前端静态资源与 API 同仓发布、同域部署（无跨域/Cookie 问题）、一次上线、一份配置，天然支持 SPA 回退（`not_found_handling = "single-page-application"`）。

## 4. 数据模型（Cloudflare D1 / SQLite）

完整建表语句见 [`infra/d1/schema.sql`](../infra/d1/schema.sql)。核心表：

| 表 | 用途 | 关键字段 |
|---|---|---|
| `users` | 用户档案 | email, password_hash, role(student/parent/admin), grade, subject, textbook_version, goal_date |
| `knowledge_points` | 知识点图谱（树） | subject, stage, grade_level, name, code(课标编号), parent_id, difficulty_base, curriculum_ref |
| `questions` | 题库 | subject, grade_level, knowledge_point_id, type, difficulty, content, options, answer, analysis, source(dataset/llm/teacher), review_status |
| `assessments` | 测评（入测/小测） | user_id, kind(diagnosis/quiz), question_ids(组卷快照), score, status |
| `assessment_answers` | 作答明细 | assessment_id, question_id, user_answer, is_correct, time_spent_sec |
| `mastery` | 掌握度 | user_id, knowledge_point_id, level(0~1), confidence, attempts, correct_count（UNIQUE(user, kp)） |
| `syllabi` | 教学大纲 | user_id, subject, title, goal, structure(JSON), version, source_assessment_id |
| `syllabus_revisions` | 大纲微调记录 | syllabus_id, diff(JSON), reason, applied |
| `lessons` | 课时 | syllabus_id, seq, title, objectives, knowledge_point_ids, status, ppt_asset_id, quiz_assessment_id |
| `assets` | 生成资产 | owner_id, kind(ppt/audio/avatar_video/image), r2_key, status(processing/ready/failed), meta |
| `ai_logs` | AI 用量 | action, model, prompt_tokens, completion_tokens, cost_cents, latency_ms（成本核算/审计） |
| `feedbacks` | 学习反馈 | user_id, lesson_id, rating, comment |

**掌握度模型 v1（Beta-binomial）**：每个知识点维护 `Beta(α, β)`，先验 `Beta(2,2)`。答对 `α+1`、答错 `β+1`；
`level = α/(α+β)`，`confidence = 1 - 3·var`（置信度随做题量上升）。样本 > 50 后可升级 IRT 2PL。

## 5. 核心模块设计

### 5.1 入测诊断（①）

- **组卷**：输入（年级、学科、教材版本、目标）。从知识点图谱按课标权重分层抽样：基础 40% / 中档 40% / 拔高 20%，每个覆盖知识点 1~2 题，共 15~20 题。题库不足 → LLM 按知识点与难度补题（`review_status=pending` 待审池）。
- **自适应（v1.5）**：两阶段——先固定 5 题摸底，再根据作答动态调整难度区间。
- **评分**：客观题自动判分；主观题（解答题）LLM 按评分标准打分 + 步骤采分点，标记需人工复核。
- **诊断报告**：知识点掌握度热力图（按章节聚合）、短板 TopN、学习建议、建议课时数。

### 5.2 老师智能体（②）

- **系统提示词动态组装**：人设（老师身份/风格/语气）＋ 学生画像（年级/教材/掌握度向量/错题本/学习历史）＋ 当前课程上下文（本课目标/课件）＋ 教学法约束（讲解→举例→提问→小结）＋ 安全约束（不聊题外、不泄露隐私、不代写作业答案的边界）。
- **工具调用**：`get_knowledge_point`、`search_question_bank`、`get_student_mistakes`、`generate_quiz`、`search_kb`（Vectorize RAG，二期）。
- **流式输出**：AI SDK `streamText` → SSE → 前端（课堂提问、答疑、错题讲解复用同一智能体）。

### 5.3 大纲生成（③）

- **输入**：诊断报告（掌握度向量）＋ 知识点图谱子树 ＋ 课标要求 ＋ 时间预算（目标日期、每周可投入课时）。
- **输出（Zod 强校验）**：`{ units: [{ title, lessons: [{ title, objectives[], knowledgePoints[], durationMin, assessment: { pre, post } }] }] }`。
- **微调闭环**：每节课后小测结果 → 掌握度更新 → LLM 生成 `syllabus_revisions`（调整后续课时侧重/难度/补弱项）→ 用户确认后应用（版本 +1）。

### 5.4 PPT 生成（④）

- **课件 JSON Schema**：`slides: [{ layout, title, blocks: [text | formula | list | table | example | practice | summary], notes(口语化讲稿) }]`；公式统一 LaTeX。
- **流水线（异步）**：`POST /api/lessons/:id/ppt` 入队 → Worker 消费：LLM 生成课件 JSON（Zod 校验）→ 存入 R2 → PptxGenJS 渲染 PPTX → R2 → `assets.status=ready` → 前端轮询/通知。
- **双产物**：PPTX（下载/打印）＋ 网页课件（KaTeX 渲染公式，供数字人课堂使用）。
- **模板系统**：自建 3~5 套版式（封面/讲解/例题/小结/练习），不依赖第三方版权模板。

### 5.5 数字人讲解（⑤）

- **形象方案（分层）**：
  - **MVP（推荐）**：2D Live2D 实时形象（`pixi-live2d-display`，客户端渲染），开发用官方示例模型 Hiyori（女师）/ Haru（男师）占位，商用前替换为定制形象或确认许可。
  - **升级路径**：腾讯智影（约 ¥6~10/分钟，实时交互 <1.5s，微信生态）/ 硅基智能（实时驱动，直播场景）/ HeyGen（真人级、多语言，跨境友好）。
- **讲解流程**：每页课件 → LLM 生成口语化讲稿 → TTS 合成音频（缓存 R2）→ 播放器同步课件翻页 + 语音 + 字幕；Web Audio 频谱驱动 Live2D 口型（motion-sync）。
- **交互**：随时暂停提问（文字，二期加语音 STT）→ 老师智能体回答 → 继续。

### 5.6 课后小测闭环（⑥）

- 每节课结束：针对本课弱点知识点（本课目标 ± 间隔复习项，基于 mastery）生成 5~8 题小测。
- 提交后：客观题自动判分 → 更新 mastery → 触发大纲微调建议（§5.3）→ 学生/家长确认 → 下一节课就绪。

## 6. API 设计（Hono 路由骨架，全部已建）

```
POST /api/auth/*                          # Better Auth 处理器（W1 接入）
GET/PATCH /api/me                         # 个人档案
GET  /api/knowledge-tree?subject=&stage=  # 知识点图谱

POST /api/diagnosis                       # 发起入测（智能组卷）
GET  /api/diagnosis/:id                   # 取试卷
POST /api/diagnosis/:id/submit            # 交卷 → 评分 → 掌握度更新
GET  /api/diagnosis/:id/report            # 诊断报告

POST /api/syllabus/generate               # 生成大纲（异步入队）
GET  /api/syllabus/:id                    # 取大纲
PATCH /api/syllabus/:id                   # 人工微调

POST /api/lessons                         # 从大纲建课时
GET  /api/lessons/:id
POST /api/lessons/:id/ppt                 # 生成 PPT（异步入队）
GET  /api/assets/:id                      # 资产状态/元信息
GET  /api/assets/:id/download             # R2 签名 URL（PPTX/音频）
POST /api/lessons/:id/explain             # 生成讲解脚本 + TTS（异步）
POST /api/lessons/:id/quiz                # 生成课后小测
POST /api/lessons/:id/quiz/submit         # 交卷 → 微调大纲建议

POST /api/chat                            # 老师智能体对话（SSE 流式）
POST /api/ai/feedback                     # 学习反馈
```

异步任务经 Cloudflare Queues（`ppt-gen` / `syllabus-gen` / `quiz-gen` / `tts-gen`），内置重试与死信队列；任务状态落 `assets.status` + KV。

## 8. 安全设计

- **认证与会话**：Better Auth（scrypt 密码哈希、httpOnly Cookie、CSRF 防护、会话过期）；OAuth（Google/GitHub）二期。
- **接口安全**：Zod 输入校验（前后端共享 DTO）；CORS 白名单；Turnstile 人机验证。
- **上传安全**：R2 上传限制类型/大小，PPT/图片做内容扫描（二期）。
- **AI 安全**：所有 LLM 输出过内容安全审核（文本），敏感词/越界指令过滤；提示词注入防护（系统提示词硬隔离，不拼接用户输入进 system）。
- **数据安全**：密码只存哈希；未成年人数据最小化；提供导出与删除（注销即删）；D1 备份加密存储。

## 9. 合规与上线注意（重要）

面向中国大陆上线 K12 教育产品，以下事项**必须在上线前完成评估**：

| 事项 | 说明 | 建议动作 |
|---|---|---|
| 生成式 AI 服务合规 | 《生成式人工智能服务管理暂行办法》——面向境内公众提供生成式 AI 服务需备案 | 使用**已备案大模型 API**（DeepSeek/通义/GLM 均已备案）+ 平台侧内容安全审核，大幅降低平台自备义务；上线前做法律评估 |
| 未成年人保护 | 《未成年人网络保护条例》《个人信息保护法》：16 岁以下需监护人同意 | 注册页监护人确认流程、隐私政策（儿童版）、防沉迷时长限制、家长端（二期） |
| 内容安全 | AI 生成文本/图片/课件需审核 | 接腾讯云天御/阿里云内容安全，违规阻断并留痕 |
| 数据出境 | D1/R2 位于 Cloudflare 境外节点，未成年人数据出境敏感 | 方案 A：将敏感个人数据与内容数据拆分（内容放境外、档案脱敏）；方案 B：国内托管主数据。上线前咨询专业意见 |
| 学科类培训边界（双减） | 义务教育阶段学科类培训受限 | 产品定位"学习辅助工具/自习工具"，不做"培训/补课"宣传，聚焦自测、查漏补缺场景 |
| 大陆访问体验 | Cloudflare 无中国大陆节点，延迟偏高 | 静态资源边缘缓存 + API 轻量化；若目标用户主要在大陆，评估"国内双轨部署"（腾讯云/阿里云 + ICP 备案） |
| 支付（二期收费） | 需企业资质 + 微信/支付宝商户 | MVP 免费 + 邀请制，冷启动 |
