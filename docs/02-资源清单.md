## 2. 生产题库策略（核心判断）

开源数据集**都不建议直接作为生产题库**（许可多为研究用途、题量/覆盖不足、无初中学段精细标注）。生产题库采用"**三层结构**"：

```
第 1 层：原创种子题（教研标注知识点/难度/解析）        —— 人工，少量但高质量
第 2 层：LLM 生成题（DeepSeek 按知识点+题型+难度生成） → 入"待审池"
         ↓ 人工抽检审核（review_status: pending → approved）
第 3 层：公开真题（仅作内部参考，不直接分发）          —— 生成变式题参考
```

**题库质检流水线**（W2 实现）：生成 → 规则校验（知识点匹配/题型/答案可验证）→ LLM 双审 → 人工抽检 → 上线。客观题必须有可自动校验的标准答案；解答题带评分标准。

## 3. 真题：可用但需克制

- **公开渠道**：中考试卷由各省市教育考试院公开发布（官网可下载 PDF）；高考真题由教育部考试院发布。
- **使用方式**：内部解析 → 生成变式题入库；或直接引用并标注来源（教学用途引用需评估）；**不将原题打包进产品分发**。
- 若追求完全干净：购买授权题库（菁优网/学科网企业授权）或纯自建。

## 5. 数字人形象许可提示

- **开发期**：Live2D 官方示例模型（Hiyori/Haru），随 Cubism SDK 提供，用于功能开发与演示。
- **商用前必须替换**：推荐（a）购买/委托 Live2D 定制形象（约 ¥500~5000/个）；(b) 使用明确 CC0/免费商用协议的模型库；(c) 3D 形象（ReadyPlayerMe 等，需核对其商用条款）。

## 6. 课程标准官方链接（知识点图谱依据）

- 教育部 2022 版义务教育课程方案与课程标准发布页：`http://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html`
- 各学科标准 PDF 在该页面正文链接（语文/数学/英语/物理/化学/生物/道德与法治/历史/地理等 16 个学科）。
- 使用方式：整理为知识点树（`infra/d1/seed.sql` 已内置初中数学示例），引用注明"依据教育部 2022 年版义务教育课程标准"。
