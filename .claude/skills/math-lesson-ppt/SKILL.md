# 初中数学精品课 PPT 生成器

> 一句话心法：**「具象模型引路 → 探究归纳出法则 → 口诀固化记忆 → 分层练习落地 → 元认知收尾」**。排版是皮，这个骨架才是骨。

## 一、金标准教学骨架（必须逐环落实）

参考 PPT（有理数的加法·第一课时）验证过的 17 页结构。**任何知识点都要能套进这个骨架**，差别只在"具象模型"换一个：

| 环节 | 参考页 | 教学动作 | 硬性要求 |
|---|---|---|---|
| ① 封面 | P1 | 标题 + 年级/学科/主讲人/学校 | 居中、绿主题、有"基础教育精品课"水印 |
| ② 回顾引入 | P2 | 激活旧知 → 抛出驱动问题 | 必须"从旧知长出新知"，不能直接灌概念 |
| ③ 探究→归纳→应用（循环 2~3 轮） | P3–13 | 用一个**具象模型**穷举所有情况 → 归纳法则 → 例题应用 | 每轮：具体→抽象，先归纳再做 |
| ④ 归纳 | P5/9/12/16 | 法则口诀化 + 运算步骤化 | 必须产出口诀/步骤（如"一看二定三算"） |
| ⑤ 应用 | P13–15 | 例题带**格式示范** → 分层练习（先口答后笔算） | 例题必须有完整解题格式 |
| ⑥ 小结 | P17 | 收获 / 困惑 / 还想知道 | 元认知三问，不要只列知识点 |

### 具象模型选择表（换知识点时据此换"引路模型"）

| 知识点类型 | 引路模型 | 对应参考PPT |
|---|---|---|
| 运算法则 | 数轴 + 运动（兔子左右移动） | 有理数加法 |
| 方程/等式 | 天平（平衡→等式两边同加减乘除） | 一元一次方程 |
| 几何概念 | 实物/折叠/度量（角、线段） | — |
| 函数 | 表格→图像→解析式三态 | — |

**规则**：概念课用"情境→列式→归类→下定义"，运算法则课用"模型→穷举→归纳法则"，两者都走同一骨架。

## 二、设计系统（照抄这套，保证"像"精品课）

- **画布**：16:9，`LAYOUT_WIDE`（13.333 × 7.5 in），白底 `#FFFFFF` 或极浅灰 `#F2F2F2`。
- **主色**：深绿 `3B5643`（标题/板块条/强调框）。
- **强调色**：绿 `136839`（口诀卡边框/勾选）、红 `993C1D`（"注意格式"警示、易错点）。
- **文字色**：正文 `2C2C2A`，次级 `5F5E5A`。
- **字体**：`Microsoft YaHei`（微软雅黑），标题加粗。
- **固定版式**：
  - 每页右上角：`基础教育精品课` 小水印（浅绿、小字号）。
  - 每页左上角：环节标签（`回顾引入`/`探究`/`归纳`/`应用`/`小结`）+ 深绿底白字小标签。
  - 标题：页面顶部一条深绿粗体标题。
- **内容卡片**：定义/法则/口诀一律放进**圆角绿边框卡片**，例题放白卡 + 左侧绿色竖条。

## 三、内容准确优先（铁律）

1. **只写教材/课标里真实存在的内容**：定义、性质、例题、练习必须与人教版教材或 2022 义教课标一致。**不许编造定理、不许编造含错答案的题**。
2. **每个例题/练习题都要有正确答案**，且我生成时要在心里/稿纸上验算一遍。
3. **内容来源优先级**：① 项目 D1 题库（`questions` 表，该知识点 approved 题）→ ② 人教版教材知识点 → ③ 课标要求。缺题时先查表，查不到再据教材补，并标 `source`。
4. **口诀/步骤**必须是"可执行、能验证"的，不是空口号。
5. 公式/符号用 LaTeX 或纯文本统一，负数、分数、未知数书写规范（如 `3x + 2 = 14`）。

## 四、产出物规格

课件最终是两份东西，缺一不可：

1. **deck JSON**（网页演示 / 数字人讲稿）：`slides[]`，每页 `{ layout, title, blocks[], notes }`。`notes` 是给数字人的**逐字口播讲稿**，口语化、亲切、像老师上课。
2. **PPTX**：由 `apps/api/src/lib/qualityDeck.ts` 的 `renderQualityPptx(deck)` 渲染。

block 类型（渲染器已支持）：`text` / `list` / `formula`（大号居中公式）/ `mnemonic`（口诀卡）/ `def`（定义卡）/ `example`（例题：`question`+`solution`）/ `practice`（练习：`question`）/ `steps`（步骤条：`items[]`）/ `columns`（双栏：`left[]`/`right[]`）/ `numberline`（数轴）/ `balance`（天平示意）/ `summary`（小结：`points[]`）。

## 五、生成工作流（照此执行）

1. **确认知识点与课时**：明确是第几课时、覆盖教材哪一节（如"3.1.1 一元一次方程"）。
2. **选具象模型**：按第二节的表选引路模型。
3. **写内容包**：`apps/api/src/lib/lessonPacks/*.ts`，结构见 `equation.ts` 示例（含每页 blocks 与 notes 讲稿）。写时过一遍第三节的准确性铁律。
4. **构建 deck + 渲染**：
   ```ts
   import { buildQualityDeck, renderQualityPptx, equationLessonPack } from "./qualityDeck";
   const deck = buildQualityDeck(equationLessonPack);
   const buf = await renderQualityPptx(deck);
   ```
5. **自检**（对照第四节质量清单逐项打勾）：
   - [ ] 六环节齐全（封面/回顾/探究/归纳/应用/小结）
   - [ ] 每个探究都有"具象模型→归纳"闭环，不是直接给结论
   - [ ] 有口诀 + 有运算/解题步骤
   - [ ] 例题有完整解题格式，练习分层（口答→笔算）
   - [ ] 每页 `notes` 讲稿口语化、无"课件上没写的内容"
   - [ ] 所有数学内容验算无误
   - [ ] 配色/字体/水印符合设计系统
